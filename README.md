# Sellify: Intelligent Second-Hand Marketplace

Sellify is a web-based marketplace for buying and selling pre-owned products.
It uses AI image recognition to identify a product from its photo and a Machine Learning model to suggest a fair resale price.
Built for the Full Stack Development Lab (24B15CS314), Jaypee Institute of Information Technology, Noida.

## Features:
User registration and login with separate buyer and seller roles
Create, edit, delete and mark product listings as sold
AI-based product category detection from uploaded images
ML-based resale price prediction with a suggested price range
Search and filter by category, price, condition and brand
Save favorite products and contact sellers
Compare listed price with the AI-estimated price
Seller/admin reports in CSV and PDF

## Tech Stack:
Python, Django
HTML, CSS, JavaScript
Machine Learning for image recognition and price prediction
